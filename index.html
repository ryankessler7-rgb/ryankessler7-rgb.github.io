    The threat landscape

    Where attackers get in.

    Most breaches don't start with a Hollywood zero-day. They start with something already broken and left unwatched. These are the vulnerability classes that show up first, and how defenders close each one.

    Critical

    Unpatched services

    Known CVEs in internet-facing software are the most common way in. Attackers scan for newly disclosed flaws within hours.

    RemediateRisk-based patch SLAs, external attack-surface scanning, virtual patching at the WAF.
    High

    Weak & reused credentials

    Default, guessable, or previously breached passwords let an attacker walk in the front door. No exploit required.

    RemediatePhishing-resistant MFA, password-manager rollout, breached-credential monitoring.
    High

    Misconfiguration

    Open cloud storage, exposed admin panels, and permissive security groups leak data without anyone attacking anything.

    RemediateCIS benchmarks, infrastructure-as-code scanning, continuous config-drift detection.
    Critical

    Injection flaws

    Untrusted input reaching a database, shell, or template lets an attacker run their own logic on your server.

    RemediateParameterized queries, strict input validation, least-privilege service accounts.
    Medium

    Weak transport security

    Traffic on legacy TLS or plain HTTP can be read or altered in transit on any shared network path.

    RemediateEnforce TLS 1.3, HSTS, modern cipher suites; retire deprecated protocols.
    Medium

    Denial of service

    Volumetric or application-layer floods exhaust bandwidth and compute until real users are locked out.

    RemediateUpstream scrubbing, adaptive rate limiting, autoscaling, anycast distribution.

    Malicious software

    Know the family, know the fix.

    Malware isn't one thing. Each family behaves differently on a host and on the wire, which means each leaves a different fingerprint and calls for a different containment move.

    MAL-01

    Ransomware

    Critical

    Encrypts files and demands payment. Modern strains steal data first, then threaten to leak it, which is double extortion.

    SignalMass file-rename bursts, shadow-copy deletion, spikes in encryption activity.ContainIsolate host, disable accounts, restore from offline backups.
    MAL-02

    Trojan / Loader

    High

    Poses as legitimate software to gain a foothold, then quietly pulls down heavier payloads.

    SignalUnexpected child processes, first-seen outbound domains.ContainQuarantine the binary, block command-and-control, hunt for persistence.
    MAL-03

    Worm

    High

    Self-propagates across the network by abusing a vulnerability, with no user action needed to spread.

    SignalLateral SMB/RDP spikes, identical processes across many hosts.ContainSegment the network, patch the exploited service, close the port.
    MAL-04

    Rootkit

    Critical

    Hides in the kernel or firmware to survive reboots and stay invisible to normal tools.

    SignalIntegrity-check mismatches, hidden processes, unsigned drivers.ContainOffline forensic imaging, then rebuild from known-good media.
    MAL-05

    Infostealer

    High

    Harvests saved credentials, session cookies, and keystrokes and ships them back to the operator.

    SignalAccess to browser credential stores, large outbound uploads.ContainForce credential rotation, revoke active session tokens.
    MAL-06

    Botnet Agent

    Medium

    Enrolls the host into a remote-controlled network used for DDoS, spam, or proxying.

    SignalBeaconing at fixed intervals to known infrastructure.ContainSinkhole the domain, remove the agent, block egress.

    The security operations stack

    The tools that watch, catch, and respond.

    Defense in depth is only as good as what you can see. These are the layers of tooling a security team runs, from the firewall at the edge to automation that reacts in milliseconds.

    Perimeter

    Firewall / NGFW

    Filters traffic by rule, application, and reputation, and carves the network into isolated zones.

    Sees: denied inbound to closed ports, egress to blocklisted hosts.
    Network detection

    IDS / IPS

    Inspects packets for known attack signatures and anomalies; an IPS can drop the bad ones inline.

    Sees: signature hits on exploit traffic, protocol anomalies.
    Correlation

    SIEM

    Centralizes logs from every source and correlates them into alerts and one searchable timeline.

    Catches: impossible travel, brute-force chains, rule + ML detections.
    Endpoint telemetry

    EDR / XDR

    Records process, file, and network activity on every host, enabling threat hunting and rollback.

    Catches: suspicious process trees, living-off-the-land binaries, persistence.
    Automated response

    SOAR

    Runs playbooks to enrich, triage, and contain alerts at machine speed, before an analyst even looks.

    Acts: auto-isolate host, disable account, open the ticket.

    Defense in depth

    No single control stops everything.

    Each layer catches what the one outside it missed, so an attacker has to beat all five in a row. The rings are the shield from the scene above, laid flat.

    1. Layer 1

      Edge

      Anycast scrubbing and reputation filtering absorb floods and known-bad sources before they touch anything.

      Stops volumetric bursts, port sweeps
    2. Layer 2

      Perimeter

      A web application firewall and adaptive rate limits inspect every request that gets through.

      Stops exploit probes, scrapers
    3. Layer 3

      Identity

      Phishing-resistant MFA and impossible-travel detection make a stolen password worthless on its own.

      Stops credential stuffing, brute force
    4. Layer 4

      Endpoint

      Behavioral EDR and application allow-listing catch what slips past the network.

      Stops malware, botnet beacons
    5. Layer 5

      Data

      Encryption at rest and data-loss prevention keep the core protected even if everything else fails.

      Stops exfiltration

    Incident response

    When something gets through.

    Detection is the start, not the end. This is the six-phase lifecycle (NIST 800-61 / SANS) that turns a 3 a.m. alert into a closed, documented case. Calm, sequenced, evidence-first.

    01

    Preparation

    Build the plan, tooling, and runbooks before anything happens. Everyone knows their role.

    02

    Identification

    Detect and confirm the incident, then scope it: which hosts, accounts, and data are touched?

    03

    Containment

    Stop the bleeding. Isolate hosts and revoke access without destroying evidence.

    04

    Eradication

    Remove the foothold: malware, persistence, and the vulnerability that allowed it.

    05

    Recovery

    Restore clean systems, watch them closely, and confirm the threat is gone before reconnecting.

    06

    Lessons learned

    Write the blameless postmortem, close the gaps, and update detections so it can't recur.

    Digital forensics

    Collect it before it's gone.

    Some evidence is gone the instant a machine powers off. The order of volatility (RFC 3227) sets the capture sequence, from the most fleeting data down to the most durable, so a live system's memory is preserved long before anyone images the disk.

    1. 1CPU registers & cachenanoseconds
    2. 2Memory (RAM) & running processesminutes
    3. 3Network connections & ARP cacheseconds
    4. 4Temp files & swap spaceminutes
    5. 5Disk & file systemsyears
    6. 6Remote logs & archived backupsyears

    What gets collected

    Memory image Disk image · write-blocked Packet capture Log timeline Registry / plist Browser & auth artifacts

    Every item is hashed with SHA-256, documented, and access-logged from seizure to analysis. That unbroken chain of custody is what lets the findings stand up, in a report or in court.
